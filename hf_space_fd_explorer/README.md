# vi-Sommelier v0 · Full-Duplex Explorer

Browse the FD stereo subset of [`tuanamz/vi-sommelier-v0`](https://huggingface.co/datasets/tuanamz/vi-sommelier-v0/tree/main/fd) — 146 dyadic Vietnamese podcast conversations, each rendered as a 2-channel stereo WAV (L = one speaker, R = the other) with a paired transcript JSON.

The dataset is **gated with manual approval**. You must be logged into HuggingFace **and approved** to hear the audio / see transcripts in this explorer. Anonymous / unapproved users will see 403 errors on audio playback.

- Request access: <https://huggingface.co/datasets/tuanamz/vi-sommelier-v0>
- Format documentation: see [`fd/README.md`](https://huggingface.co/datasets/tuanamz/vi-sommelier-v0/blob/main/fd/README.md) in the dataset
